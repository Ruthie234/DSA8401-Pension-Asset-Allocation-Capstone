# API input example

`POST /predict` expects a JSON object with 26 required fields. Use the automatically generated Swagger interface at `/docs` to inspect and submit the full schema. Do not invent or approximate values for a substantive regulatory prediction.

For a smoke test only, you may use one feature row from the existing `prediction_input_smoke_test.csv` file created during the command-line prediction test. Copy its exact values into the matching fields in `/docs`. This only checks API connectivity and model invocation; it is not an independent model-performance evaluation.
